Blueprint Studio — portfolio website for Chinguun & Shinezaya. Built with Next.js 15 and Tailwind CSS.

## Getting Started

Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

Pages live in `src/app` (App Router). Edit `src/app/page.tsx` for Home, etc.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Build & Preview

```bash
npm run preview
```

## Deploy

- Vercel (recommended): Import the repo, set Framework to Next.js, deploy.
- Static export (limited features): `npm run export` → outputs to `out/`.
